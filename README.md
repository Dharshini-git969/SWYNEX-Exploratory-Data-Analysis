# SWYNEX - Exploratory Data Analysis

## Task 2

This project was completed as part of my internship with SWYNEX Technologies.

The objective of this task was to perform Exploratory Data Analysis on the cleaned online retail dataset prepared during Task 1.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed

- Dataset overview
- Descriptive statistics
- Missing-value analysis
- Country analysis
- Product analysis
- Quantity analysis
- Unit price analysis
- Sales value analysis
- Cancellation analysis
- Monthly sales trends
- Customer analysis
- Correlation analysis
- Outlier detection

## Key Findings

- United Kingdom dominates transaction volume and recorded sales value.
- November 2011 had the highest recorded monthly sales value.
- Quantity and SalesValue have a strong positive correlation of 0.89.
- 9,251 cancellation records have negative quantities.
- 135,034 transactions do not have a CustomerID.
- Customer 14646 has the highest recorded customer sales value.
- Significant outliers exist in Quantity and UnitPrice.

## Conclusion

The EDA identified important trends, patterns, customer behavior, cancellation patterns and anomalies in the online retail dataset.
